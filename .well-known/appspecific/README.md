# Tesla Fleet public key

Put the Home Assistant Tesla Fleet API **public** key in this folder as `com.tesla.3p.public-key.pem`.

GitHub Pages will serve it at:

https://jochenseiler-byte.github.io/.well-known/appspecific/com.tesla.3p.public-key.pem

Only the public key belongs here. Do not commit a private key or any other secret.
